# Palimpsest Heritage Archive — Upgrade 0.6

## Added in this upgrade
1. Curated Collections route with themed artifact groups.
2. Chronology Timeline route with period filtering.
3. Research Workspace with document library and local notebook.
4. Six built-in research documents with readable web versions and Markdown export.
5. Four additional project documentation files in `/docs`.
6. Local research-note persistence using browser storage.
7. Research-note Markdown export.
8. Installable PWA shell with manifest and service worker.
9. Print-friendly document styles.
10. Clear frontend/backend integration blueprint for the next phase.

## Run
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

Everything remains frontend-only and can be connected to a backend later without changing the core navigation model.
